# Power-BI
Developed an interactive IPL analytics dashboard in Power BI using 2008–2025 match and ball-by-ball data. Applied DAX, data modelling and Power Query to analyse team performance, player statistics, Orange/Purple Cap holders, boundaries, centuries, match outcomes and season-wise trends through dynamic visualisations and filters.

Project Objective:
To transform raw IPL match and ball-by-ball data into an interactive analytical dashboard that enables users to quickly understand season-wise team performance and individual player achievements.

🔍 Key Analysis
Analysed team performance across seasons, including matches played, wins, losses, no-results and total points.
Identified Orange Cap and Purple Cap holders, along with their runs, wickets and respective teams.

Analysed top performers for boundaries, including most fours and sixes.
Calculated centuries and half-centuries across IPL seasons.
Presented season champions and runners-up dynamically.
Added player images and team logos to create an interactive and visually engaging dashboard.

Used DAX measures, filtering, summarisation and context-based calculations to make the dashboard dynamically respond to the selected IPL season.
